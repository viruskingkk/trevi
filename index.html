RocketMQ 部署 YAML 產生器

UAT / prod 無 kubectl 權限，使用此功能產生完整 YAML，直接在 Kuboard「Create from YAML」貼入部署。
包含：Namespace · ConfigMap（broker conf + start script）· StatefulSet（nameserver x2 · broker-master · broker-replica）· Deployment（dashboard）· Service（nameserver + dashboard）
